# @lumina/client

Typed TypeScript client for the [Lumina](https://github.com/Lumeeena/lumina-backend)
GraphQL API, generated from its schema. Variables and results are typed, so
you write no types by hand.

```ts
import { createLuminaClient, TransactionsDocument } from '@lumina/client';

const lumina = createLuminaClient({ url: 'https://api.example.com/graphql', apiKey });
const { transactions } = await lumina.request(TransactionsDocument, { limit: 20 });
transactions.items[0]?.hash; // string
```

Install the version matching the server you talk to. Shipped operations,
errors, typing your own queries against the bundled `schema.graphql`, and how
the package is regenerated on release:
[docs/CLIENT_SDK.md](https://github.com/Lumeeena/lumina-backend/blob/main/docs/CLIENT_SDK.md).

`src/generated/` is generated by `npm run generate`; do not edit it.
